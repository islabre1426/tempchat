# tempchat
A temporary chat website, powered by PeerJS

## Dependencies
- NodeJS + npm
- Unix utilities (basename, sed, tr, etc.) (Git Bash or a Unix-like OS preferred)
- rsync
- ssh (for authorizing remote server, setup first)
